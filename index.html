PeatWatch

Jaga gambut tetap basah, sebelum api datang.

Konsep aplikasi pemantauan kawasan gambut rawan kebakaran untuk warga desa, Masyarakat Peduli Api, dan petugas lapangan. Data sensor kelembapan, satelit titik api, dan cuaca digabung menjadi satu status risiko yang mudah dipahami.

  • Monitoring titik apiData satelit VIIRS & MODIS
